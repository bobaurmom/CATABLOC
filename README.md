# Catabloc

An interactive, gamified learning platform for freshman student to learn about specific algorithm building for absolute begginer.

## 🚀 Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Containerization:** Docker

## 🛠️ Development Setup

1.  **Prerequisites:** Ensure you have installed:
    - [Docker](https://www.docker.com/products/docker-desktop)
    - [Git](https://git-scm.com/)

2.  **Clone and run:**
    ```bash
    git clone <repo-url>
    cd catabloc
    docker-compose up
    ```

3.  **Open your browser:**
    - Frontend: http://localhost:3000
    - Backend API: http://localhost:8000 
    - API Docs: http://localhost:8000/api-docs (coming soon!)

## 🏗️ Building New Features

1. Create a new branch: `git checkout -b feat/my-new-feature`
2. Make your changes in the `/frontend` or `/backend` folders.
3. Test your changes: `docker-compose up --build`
4. Commit and push your changes.
5. Create a Pull Request to merge into `main`.
